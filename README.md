# AWS Cloud Computing and DevOps Project

## Project Overview
This project demonstrates the basics of web development, cloud computing, and DevOps. It includes a simple static website built using HTML and CSS and prepared for web hosting.

## Technologies Used
- **HTML** – Structures the website content.
- **CSS** – Styles the website.
- **GitHub** – Stores and manages the project source code.
- **GitHub Pages** – Hosts the website online.
- **AWS S3** – Included as a cloud-hosting technology to learn and explore.

## Project Objectives
- Create a simple and responsive website.
- Learn version control and source-code management.
- Understand website hosting and cloud computing concepts.
- Explore basic DevOps practices.

https://aaliyafirdouse-ctrl.github.io/AWS-DevOps-Project/

## Project Status
The static website is published using GitHub Pages. AWS S3 hosting is a planned learning objective and has not yet been configured.
